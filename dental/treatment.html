GENERALむし歯・歯周病の治療

むし歯は、小さいうちに治せば削る量も通う回数も少なくてすみます。当院では「できるだけ削らない・抜かない・神経を残す」治療を基本に、お口の写真とレントゲンをモニターでお見せしながら、治療の内容と回数をご説明してから始めます。歯周病は、日本人が歯を失ういちばんの原因です。歯ぐきの検査と歯石の除去、毎日の歯みがきの見直しで進行を止めます。

治療の流れ

  1. 初診　お口の写真・レントゲン・歯ぐきの検査。痛みが強いときは応急処置を行います。
  2. ご説明　治療の選択肢、回数、費用の目安をお伝えします。
  3. 治療　表面麻酔のあと、細い針と電動注射器でゆっくり麻酔をしてから治療します。
  4. メインテナンス　治療後は3か月ごとの検診で、再発を防ぎます。

白い詰め物（保険）1本 3,000〜6,000円程度

PREVENTIVE予防歯科・クリーニング

痛くなってから治すより、痛くならないように通う。それがいちばん歯を残せる方法です。3か月に1回の検診とクリーニングで、むし歯や歯周病を早い段階で見つけます。当院では担当の歯科衛生士が毎回同じ方を担当するので、前回との小さな違いにも気づけます。

治療の流れ

  1. 検診　お口の写真を撮り、前回と見比べながら変化を確認します。
  2. クリーニング　歯石と着色を落とし、歯の表面を磨きます。
  3. 歯みがきの見直し　磨き残しやすい場所を写真でお見せし、道具の選び方もお伝えします。
  4. フッ素塗布　むし歯になりやすい方、お子さまにおすすめしています。

費用の目安

定期検診・クリーニング（保険）1回 3,000〜4,000円程度
PMTC（自費）1回 8,800円
フッ素塗布1回 1,100円

保険診療の金額は3割負担の目安です。自費診療は税込です。

PEDIATRIC小児歯科

お子さまの歯科治療で大切なのは、「歯医者はこわくない」と感じてもらうこと。当院では、まず診療台に座る練習、器具を見る練習から始めます。泣いてしまっても、無理に治療は進めません。フッ素塗布とシーラントでむし歯を防ぎ、歯みがきの仕方も親子でお伝えします。キッズスペースと、保育士資格のあるスタッフがいます。

治療の流れ

  1. はじめて　診療台に座る、お口を開ける練習。できたらその日は終わりでも大丈夫です。
  2. 検診とフッ素　3か月に1回、むし歯のチェックとフッ素塗布。
  3. シーラント　奥歯の溝を埋めて、むし歯を防ぎます。
  4. 歯ならびの相談　噛み合わせや指しゃぶりなど、気になることは早めにご相談ください。

費用の目安

お子さまの検診・フッ素塗布医療証をお持ちの方は自己負担なし
シーラント（保険）1本 500〜1,000円程度

保険診療の金額は3割負担の目安です。自費診療は税込です。

ORTHODONTICS矯正歯科

月2回（第2・第4土曜）、矯正専門の歯科医師が診療します。お子さまの歯ならびの相談から、大人のマウスピース矯正まで。相談は無料で、始めるかどうかはゆっくり決めていただけます。

治療の流れ

  1. 無料相談　お口の状態を見て、矯正が必要か、どんな方法があるかをお話しします。
  2. 精密検査　レントゲン・写真・歯型をとり、治療計画をつくります。
  3. 治療開始　装置をつけ、月1回の調整に通っていただきます。
  4. 保定　治療後は、後戻りを防ぐ装置を使います。

WHITENINGホワイトニング

歯を削らずに白くする方法です。ご自宅で行うホームホワイトニングと、医院で行うオフィスホワイトニングがあります。歯の状態によっては向かない場合もあるので、まず検診をしてからご提案します。

治療の流れ

  1. 検診　むし歯や歯周病があれば、先に治療します。
  2. ホームホワイトニング　お口に合わせたマウスピースを作り、ご自宅で2週間ほど。
  3. オフィスホワイトニング　医院で薬剤と光を使い、1回60分。
  4. 色の戻り　半年〜1年で少しずつ戻ります。タッチアップで維持できます。

費用の目安

オフィスホワイトニング1回 33,000円

PROSTHETICS入れ歯・インプラント

歯を失ったあとの選択肢は、入れ歯・ブリッジ・インプラントの3つです。それぞれの良いところと注意点をご説明し、生活に合う方法をいっしょに決めます。合わない入れ歯の調整や作り直しも承ります。インプラントは、提携する口腔外科と連携して行います。

治療の流れ

  1. ご相談　いまのお困りごと（噛めない、外れる、痛い）を伺います。
  2. 検査　レントゲンと歯型をとり、残っている歯の状態を確認します。
  3. ご提案　入れ歯・ブリッジ・インプラントのそれぞれの費用と期間をお伝えします。
  4. 製作・調整　できあがったあとも、合うまで何度でも調整します。

費用の目安
